No-photo design system

Cuisine-color gradient + faded native-script ornament + clean typography hierarchy + "What to order" dishes block. Zero borrowed imagery. Each card uses the cuisine's actual flag-derived palette so a Bangladeshi spot reads green, an Uyghur spot reads blue, a Kurdish spot reads purple — visual identity comes from culturally-rooted color, not stock photos.

Third cuisine, third color, same system — recognizable as "NowServingTO" instantly

Honest read

  • The design system holds across cuisines. Three different colors (green / blue / purple) with the same typographic + ornament structure — recognizable as one brand, distinctive per cuisine.
  • The native-script ornament does cultural work without depicting people. Even with Latin fallbacks (BANGLA / UYGHUR / KURDÎ), the watermark creates richness. Swapped to actual scripts (বাংলা / ئۇيغۇر / کوردی) once Noto fonts are installed on the rendering box, it would feel even more culturally specific.
  • The "What to order" line is the workhorse. "dhaka chaap kebab, beef hari kebab, butter chicken, dhaka beef tehari" sells the spot better than any storefront photo would. The dishes data we extract via Haiku turns out to be the visual replacement for photos.
  • Cost to build for real: ~1 day. Modify build_trends_card_svg() in og_card.py to use this template, parameterize per-entry color + ornament + dishes. Sample cuisines done; the cuisine→color + cuisine→native-script tables exist or are short.
  • Hybrid possibility: use photo OG card when photo is strong (Star Glow Boba storefront), use this typographic version when photo is weak (Petro Canada gas station). Best of both — let the visual win where it exists, never display embarrassing photos as your hero card.
